# Dokumentacja v0.4

To jest pełny, zamrożony snapshot dokumentacji technicznej po zatwierdzonych
zmianach względem v0.3. Zachowuje ten sam zestaw dokumentów i identyfikatory
kryteriów. Różnice są opisane wyłącznie w
[`CHANGES-FROM-v0.3.md`](CHANGES-FROM-v0.3.md), a decyzje właściciela w
[`ACCEPTED-DECISIONS.md`](ACCEPTED-DECISIONS.md).

## Zakres

Wersja obejmuje kanoniczną architekturę, wygenerowaną macierz odbioru i backlog,
kontrakt nowej aplikacji, adaptery, obserwowalność, odzyskiwanie stanu oraz mapę
dokumentacji. Raporty historyczne i dowody pozostają poza snapshotem, ponieważ
mają własne daty oraz pochodzenie.

## Źródło

- baza: `docs/versions/v0.3/`;
- stan kodu: gałąź integracyjna po zmergowaniu minimalnej bramki GLM;
- status: przygotowane do przeglądu, niezatwierdzone jako wydanie Git;
- następna wersja: powstaje dopiero z kolejnej zaakceptowanej zmiany decyzji lub
  architektury.

Nie edytuj plików w tym katalogu po odbiorze. Zmiany wprowadza się najpierw do
aktywnej dokumentacji i publikuje jako nowy pełny snapshot.
