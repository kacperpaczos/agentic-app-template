# Wersje dokumentacji

Ten katalog przechowuje niezmienne punkty odniesienia kanonicznej dokumentacji
technicznej. Aktywne pliki pozostają bezpośrednio w `docs/`; katalog wersji nie
zastępuje archiwum raportów ani dowodów.

| Wersja | Status | Zakres |
|---|---|---|
| [v0.3](v0.3/ARCHITECTURE.md) | zamrożona baza | stan przed zatwierdzonymi decyzjami v0.4 |
| [v0.4](v0.4/README.md) | aktualna do przeglądu | pełny snapshot v0.3 z decyzjami o GLM, klasach wymagań, UI agenta, centrum zadań i trybach zgód |

Nowa wersja powstaje dopiero po uzgodnieniu i odbiorze zmian w aktywnej
dokumentacji. Każda wersja zawiera własny manifest źródła i listę różnic.
