## Efekt uboczny do wiadomosci

Budowanie z --no-cache NIE uzywa cache, ale nadal go ZAPISUJE. Po tej pracy
`docker system df` pokazuje 9,75 GB build cache (8,86 GB do odzyskania).
Czesc pochodzi z innych obrazow uzytkownika (caddy, n8niframe, playwright),
wiec nie czyszcze tego samodzielnie. Do odzyskania miejsca:

  docker builder prune            # sam cache budowania
  docker builder prune -a         # agresywniej
  docker image prune              # obrazy bez tagow
